# Healthcare Patients – Clean Data Analysis

## Project Overview
This project presents an analysis of a synthetic healthcare patient dataset containing 600 patient records and 11 attributes.

## Objectives
- Assess data quality and check for missing values and duplicate patient IDs.
- Summarize numerical and categorical patient attributes.
- Examine 30-day hospital readmission rates by diagnosis.
- Present key findings in a report.

## Key Findings
- Patient records analyzed: 600
- Missing values reported: 0
- Duplicate patient IDs reported: 0
- Mean patient age: 50.99 years
- Mean length of stay: 9.38 days
- Overall 30-day readmission rate: 29%

## Deliverable
See `Healthcare Patients – Clean Data Analysis.pdf` for the analysis report.

## Data Note
The report describes the dataset as synthetic. The results are descriptive and should not be interpreted as clinical conclusions.
